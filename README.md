# 유카데미 잉글리시

초등부를 중심으로 학원·강사·중고등부·학원 소식·상담을 소개하는 6개 페이지 웹사이트입니다.

## 실행

Node.js 22 이상에서 추가 패키지 설치 없이 실행합니다.

```sh
npm run build
npm run check
npm run dev
```

개발 주소는 `http://127.0.0.1:4173/`입니다. 빌드 결과는 `dist/`에 생성됩니다.

## 페이지

- `/` 홈
- `/teacher/` 강사소개
- `/about/` 유카데미 소개
- `/elementary/` 초등부
- `/secondary/` 중·고등부
- `/contact/` 상담·오시는 길

## 콘텐츠 수정

페이지 본문은 `src/pages/`, 교재 목록은 `src/course-books.mjs`, 공통 디자인은 `src/styles/site.css`, 공통 헤더·푸터와 메타데이터는 `scripts/build.mjs`에서 관리합니다. 수업료는 사이트에 표시하지 않습니다. 상담 정보는 기존 공개 구글폼과 카카오 오픈채팅으로 연결하며 이 사이트는 개인정보를 직접 입력받거나 저장하지 않습니다.

## Vercel 배포

GitHub 저장소를 Vercel에 Import합니다. `vercel.json`의 빌드 명령 `npm run build`, 결과 폴더 `dist`를 사용합니다. 외부 DB·API 키·환경변수가 필요하지 않습니다. `SITE_URL`을 지정하면 해당 주소로 canonical·사이트맵을 생성합니다. Vercel 배포에서는 production 도메인을 자동으로 사용합니다.

## 자산과 운영

제공된 유카데미 로고와 유카몬을 사용합니다. 원본 조사 문서, 학생 개인정보, 인증 정보, 이미지 생성 중간 파일은 공개 저장소에 포함하지 않습니다. 원장 경력은 블로그 게시 당시의 소개와 현재 상태를 구분하고, 과거 지도 후기는 개원 후 실적으로 합산하지 않습니다. 공식 세부 방문 위치와 현재 모집 일정은 운영자가 확정한 뒤 추가할 수 있습니다.

Pretendard는 고정 버전의 공식 배포 CDN에서 로드하며, 자세한 자산 출처는 `ASSETS.md`에 정리했습니다.

## 2026-11-11 개편

유카데미 소개에 학원 소식과 교실 안내를 통합했습니다. 기존 `/stories/`는 `/about/#news`로 영구 이동합니다. 강사소개에 익명화한 네이버 학부모 후기 요약 5건을 추가하고 과거 제자 후기와 구분했습니다. 캐릭터는 홈 히어로와 홈 하단 상담 영역에만 사용합니다. 후기 원문 확인일은 2026-11-11이며 변경 시 원문을 확인해 수동 갱신합니다.
